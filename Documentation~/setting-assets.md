# Setting Assets

Types to allow customization of IETs, and to improve authoring.

| Type | Description |
| :---- | :---- |
| [Tutorial Project Settings](tutorial-project-settings.md) | Contains general settings of your tutorial project. |
| [Tutorial Styles](tutorial-styles.md) | Use it to customize the visual appearance of Tutorials and Masking. |
| [Masking Preset](masking-presets.md) | Create a reusable Masking preset to share between different Tutorial Pages. |
