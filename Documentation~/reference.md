# Reference

This section contains a reference guide of all the asset types (ScriptableObjects) that are part of Tutorial Framework.

| Category | Description |
| :-------- | :--------------- |
| [Content Assets](content-assets.md) | Used to structure tutorials, as well as to store the actual content (text, images, video and so on) that the users interact with. |
| [Setting Assets](setting-assets.md) | Various types used for styling and configuring the tutorial project. |
