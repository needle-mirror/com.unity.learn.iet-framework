# Content Assets

Tutorial Framework uses four key assets to create and structure IETs:

| Type | Description |
| :---- | :---- |
| [Tutorial Container](tutorial-containers.md) | Tutorial Containers let you organize content into macro areas. |
| [Tutorial](tutorials.md) | Tutorial assets represent the units of the learning experience, and contain one or more Tutorial Pages. |
| [Tutorial Page](tutorial-pages.md) | Tutorial Pages contain the actual tutorial content visible to the user: text, images, videos and instruction steps. |
| [Tutorial Welcome Page](tutorial-welcome-page.md) | Represents a welcome dialog that appears to users when they first open the project. |
