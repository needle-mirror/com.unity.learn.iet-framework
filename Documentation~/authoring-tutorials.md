# Authoring Tutorials

To create and edit tutorials, you need to install the [Tutorial Authoring Tools] package in addition to Tutorial Framework.

Once that is done, head to the [Creating Tutorials guide](https://docs.unity3d.com/Packages/com.unity.learn.iet-framework.authoring@2.1/manual/creating-tutorials.html) in the Authoring package's documentation to understand how to build a new tutorial from scratch.

[Tutorial Authoring Tools]: https://docs.unity3d.com/Packages/com.unity.learn.iet-framework.authoring@2.1
